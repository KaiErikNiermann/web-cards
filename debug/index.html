Mask animation debug

Not meant for user-facing content: a performance debugging utility for developers. It draws a number of rounded boxes whose child spins with a CSS transform animation; the variant changes only how each box is clipped. Firefox runs such an animation on the main thread when an ancestor has a mask or clip-path (bug 1923933), which costs frames with its software compositor. Only boxes on screen cost frames: shrink them to fit more in view. Compare the frame rate in the overlay across variants, counts and sizes. The overlay itself costs some frames in Firefox (about 20% with 60 spinners on screen): untick it to see the page without it.
